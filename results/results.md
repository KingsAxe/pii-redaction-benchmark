## Definitions and limits

- Strict: same mapped type and exact span. Overlap: same mapped type and nonzero overlap, using the unchanged Phase 2 one-to-one greedy matcher. ID precision is per-class precision under that full assignment. A zero score with no ID predictions is the scorer's convention.
- Leak and exposure are type-agnostic across mapped prediction spans. Raw labels are retained; unmapped labels do not count as redaction, following the Phase 2 scorer.
- Decoy-hit predictions use the scorer's unmatched-prediction/first-overlapping-decoy rule. ORDER_ID decoys hit by ID counts distinct decoy annotations touched by any mapped ID span.
- IDs assigned PHONE are the matcher's ID-to-PHONE assignments. An entity is fully uncovered when no mapped predicted characters cover it; partly uncovered means at least one but not all characters exposed.
- Timing records analysis calls only, after five unrecorded dev warm-ups. Main median/p95 use all stored test timings and the Phase 2 percentile helper. The unchanged scorer additionally drops the first five stored timings; its original latency output is retained in evaluation_details.json and the explicitly named scorer columns in results.csv. No scoring or data were changed.
- custom_generic is archived experiment 01; custom is experiment 02. The generator never emits BVN/NIN IDs starting with 0, which benefits custom's nonzero-leading rule. Bare random order IDs remain ambiguous. This is synthetic, template-based, small-scale evaluation with one spaCy model.
- Latencies are single sequential runs on this machine and may reflect cache, host load, and run order; they do not establish a universal speed ranking.
- Full scorer outputs, denominators, source hashes, and prediction hashes are in evaluation_details.json. All error records with snippets are in error_analysis.md.
